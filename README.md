# Farm to Home

A responsive website concept for the Farm to Home Food startup described in the presentation. It uses plain HTML, CSS, and JavaScript and has no build step.

## Run locally

Open `index.html` in a browser or serve this folder with any static file server.

## Deploy

- **Netlify:** drop the project folder or source ZIP into Netlify Drop. Publish directory: `.`.
- **Vercel:** import the project or upload its files as a static site. Framework preset: Other. Output directory: `.`.
- **GitHub Pages:** push the project files to a repository and enable Pages from the repository's Settings, using the root folder as its source.

The page includes product filters and a mobile navigation menu. The startup, delivery and product range are presented as a concept/pilot plan; this site does not process orders.
